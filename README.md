Telecom Customer Intelligence – Machine Learning Capstone Project

This project focuses on analyzing telecom customer data and applying Machine Learning techniques to generate valuable business insights and support data-driven decision-making.

Project Objectives

* Analyze customer behavior and telecom service usage.
* Predict monthly customer bills using Regression models.
* Build Churn Prediction models to identify customers at risk of leaving.
* Apply Clustering techniques to segment customers based on their usage behavior.
* Use Association Rule Mining to discover relationships between purchased telecom services.
* Analyze the relationship between customer segments and churn rates.

Machine Learning Techniques

* Regression
* Classification
* Clustering
* Association Rule Mining
* Model Evaluation and Hyperparameter Tuning

Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, MLxtend, Jupyter Notebook.

Project Outcome

The project aims to transform raw telecom data into actionable insights that can help improve customer retention, understand customer behavior, and support better business strategies.
